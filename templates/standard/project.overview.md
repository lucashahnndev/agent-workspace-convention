# Project Overview

This is the root overview for agent-oriented navigation in the project.

If you are human, start with `README.md`.
If you are an agent, use this file as the map, then continue to `agent-start-here.md`.

## What lives where

- `README.md`: human landing page.
- `agent-start-here.md`: operational entry point for the agent.
- `agent/README.md`: workspace map for the agent.
- `agent/specs/README.md`: normative contracts and state.
- `agent/policy/README.md`: durable agent rules.
- `docs/README.md`: human-facing documentation, context, and continuity.

## Suggested reading order for agents

1. `project.overview.md`
2. `agent-start-here.md`
3. `agent/specs/README.md`
4. the relevant `.spec` and `.stat`
5. `agent/policy/README.md`
6. `docs/README.md` when human context helps
